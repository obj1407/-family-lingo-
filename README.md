# 🦉 우리집 듀오링고 | 300일 영어 챌린지

가족과 함께하는 맞춤형 영어 학습 웹앱입니다.  
듀오링고처럼 매일 20문제씩, 300일 동안 꾸준히 영어를 공부해보세요!

## ✨ 주요 기능

- 🌱 **3단계 난이도**: 초급 / 중급 / 고급
- 📅 **300일 챌린지**: 날짜별로 매일 다른 문제 출제
- 🎯 **20문제 세션**: 한 번에 20문제씩 집중 학습
- 🔥 **연속 학습일 (Streak)**: 매일 공부한 날 기록
- ⭐ **XP 시스템**: 문제 맞힐 때마다 경험치 획득
- ❤️ **하트 시스템**: 틀리면 하트 감소 (5개)
- 💾 **자동 저장**: LocalStorage로 진행 상황 저장

## 🚀 GitHub Pages 배포 방법

1. 이 저장소를 GitHub에 업로드
2. 저장소 **Settings** → **Pages** 이동
3. **Source**를 `main` 브랜치로 선택
4. 저장 후 1-2분 기다리면 웹 주소가 생성됩니다
5. 생성된 URL로 접속하면 바로 사용 가능!

## 📱 사용 방법

1. `index.html` 파일을 브라우저로 열기
2. 난이도 선택 (초급/중급/중급/고급)
3. 20문제 풀기
4. 결과 확인 후 내일 다시 도전!
